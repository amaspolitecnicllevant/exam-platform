# Fer un examen a la plataforma — resum d'una pàgina

**1. Entra.** Obre l'adreça que t'ha donat el professor i escriu el correu i la contrasenya. Si encara no tens compte, fes servir el **link
de convit** del professor. Canvia la contrasenya la primera vegada (botó de la barra lateral). Si el navegador avisa que la connexió no és
segura, **no continuïs** i avisa el professor.

**2. Tria l'examen.** A *Els meus exàmens* hi ha els que pots fer ara. Alguns només es poden fer des d'una **aula** concreta.

**3. Comença.** Al prémer-lo, comença el **compte enrere** (a dalt, sempre visible). Veus el teu nom i el teu correu a la capçalera.

**4. Respon.**

| Pregunta | Què fas |
|:--|:--|
| Test | Tries una opció |
| Resposta curta o llarga | Escrius la resposta |
| Comanda, script o Java | Escrius el codi i prems **▶ Executar** per provar-lo (sense internet; la classe Java s'ha de dir `Main`) |
| Lliurament de fitxer | **Tries un fitxer** del format que diu la pregunta (màxim 10 MB); el pots substituir o esborrar fins que entreguis |

**5. El desament és automàtic.** Mira l'estat a dalt: *pendent, desant, desat, error*. Si veus **error**, la resposta potser no s'ha
desat: quan torni la connexió, **toca-la de nou** i espera el «desat». Si et cau el navegador, torna a entrar i continua: el temps no s'ha parat.

**6. Entrega.** Prem **Entregar** i confirma: després no es pot canviar res. Quan el temps s'acaba, **s'entrega sol**. Surt un avís als 10 minuts i a l'últim minut.

**7. Després.** Veuràs «pendent de correcció» fins que el professor publiqui les notes. Les trobaràs a *Historial i notes*.

**Recorda**

- Només pots fer servir **apunts** en les preguntes que ho diuen.
- Cada **canvi de pestanya o de finestra** queda registrat i el professor ho veu. No tanquis la pestanya de l'examen fins que hagis entregat.
- Si entregues per error, demana al professor que et **reiniciï la sessió**; les respostes es conserven.
- Si alguna cosa falla, **avisa el professor al moment**, sense sortir de l'examen.

*Guia completa: «Guia de l'alumne».*
